# Instatoon

인스타툰 작업 자료를 모아둔 저장소입니다.

현재 핵심 프로젝트는 **박똥똥 씨 (가제)** 시즌 1입니다.  
51세 막내딸이 89세 어머니와 91세 아부지를 돌봐온 시간을 바탕으로 한 회고록형 인스타툰입니다.

## 작품 개요

- 형식: 인스타그램 캐러셀 인스타툰
- 시즌 1 분량: 총 45화
- 구조: 현재 15화 + 과거 회상 30화 교차 구성
- 핵심 장치: 1화와 45화의 수미상관
- 클라이맥스 구간: 30화~33화
- 톤: 자기연민보다 절제, 원망보다 사실 묘사, 무거움 속의 작은 다정함
